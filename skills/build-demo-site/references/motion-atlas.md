# Reusing Motion Atlas

Requested on 23 November 2026: make useful effects portable and document selective use. Canonical source is `simonridd/demo-sites`, `kits/shorts-lab/effects/`; inspect `registry.json`, `README.md` and the actual examples at `/kits/shorts-lab/effects/`. This update makes a library available; it does not adopt every decorative study as a product default or change existing customer routes.

1. Establish audience, task and benefit. Search the registry and Co-op before inventing a new component. Retain the stable Atlas ID when extending an existing effect.
2. Copy the complete effect directory with original assets and the retained Dice UI MIT notice for the comparison recipe. Mount the selected markup with `mountEffect`; do not add a framework or animation dependency solely for an effect. Preserve site-prefix asset URLs.
3. Use the existing target owner: customer component for websites, storyboard/scene lifecycle for presentations, real data/voice/readiness owner for demo applications. `setState` and `setLoading` accept owner state. Never let an animation announce readiness, a payment, real listening or completion.
4. Default to quiet/static states. Use comparison sliders for visual case studies, skeletons for genuinely pending content, and short stagger/entrance for a relevant explanation. Reserve moving patterns, marquees, colour waves, sprites and aurora titles for justified hero/stage moments. Keep task labels/body/navigation still and legible.
5. Keep native keyboard/touch semantics and content without motion. The comparison supports a side-by-side static alternative. Render fallback markup in the target's own server/static renderer; the generated playground itself needs JavaScript. Keep accessible text singular, decorative copies hidden and DOM comparison copies inert.
6. Suspend offscreen/background motion, honour initial/changed reduced motion and call `destroy()` before removing a component/scene. Cancel real pending requests through their owning system. Preserve existing navigation, URLs, fragments, media/audio controls and integration gates.
7. Test the changed target at desktop, narrow and enlarged text sizes, keyboard/touch, no-script/static, initial/changed reduced motion and failure/cancel/retry. Record actual browser/engine evidence separately from physical-device performance and publication.

The optical study uses SVG pixel displacement of a bounded authored scene. It does **not** claim arbitrary DOM backdrop refraction. Optional native media hotspots use allowed local destinations; ImageKit player/commerce/account connection remains a separate integration. Keep the original research-only entries honest.

The library's CSS/JS is native and scoped under `.ma-effect`. No global auto-mount or visitor packages are added. See `kits/shorts-lab/RECONCILIATION.md` for prior studies, backlog mapping, reused sources, acceptance and limits. A PR is reviewable source, not a published Pages revision or an installed runtime in another application.
